## 1. Official vMix Baseline & Research Sources

### Official Sources Consulted (Research Date: October 23, 2026)
1. **vMix Official Features Specification:** `https://www.vmix.com/software/features.aspx`
2. **vMix Edition Comparison Table (Basic HD, HD, 4K, Pro, Max):** `https://www.vmix.com/software/supported-hardware.aspx` & `https://www.vmix.com/purchase/`
3. **vMix 27 / 28 Online User Guide & Technical Documentation:** `https://www.vmix.com/help27/` & `https://www.vmix.com/help28/`
   - *Mix Inputs (vMix 27/28):* Up to 4–16 independent Mix inputs (mini-switchers) with dedicated Preview/Program/Transition buses.
   - *vMix Call:* Browser-based WebRTC remote guest contribution (1 in HD, 4 in 4K, 8 in Pro/Max) with automatic audio mix-minus and configurable video return.
   - *Instant Replay:* Continuous multi-camera recording buffer (1 camera in HD, up to 8 cameras in Pro/Max) with slow-motion playout, event tagging, and sub-clip export.
   - *GT Title Designer & Data Sources:* Vector animated titles with live CSV, JSON, XML, Google Sheets, and RSS data bindings, plus Photoshop `.psd` layer import.
   - *Audio Production:* Per-input EQ, Compressor, Noise Gate, VST3 plugins, Master + 7 stereo Aux buses (M, A–G), 16x16 channel routing matrix, and ASIO support.
   - *Outputs & Hardware:* Up to 4 independent external/virtual/NDI/SRT/SDI outputs (`Fullscreen` x2, `External` x2–4), MultiCorder ISO recording (4K/Pro/Max), DeckLink/AJA SDI key/fill & genlock, and up to 3–5 simultaneous RTMP/SRT streams.

### vMix Capability Distinction Framework
- **Tier 1 — General vMix Capabilities (All Editions):** Dual-bus Preview/Program switching, 10+ transitions, 4 overlay channels, multi-layer composition (10 layers), RTMP streaming, MP4/MKV local recording, built-in EQ/Compressor/Gate, GT vector titles, UVCs/RTSP/screen capture, and web/MIDI/hotkey control.
- **Tier 2 — Edition-Gated Capabilities (4K / Pro / Max):** Mix Inputs 2–16 (4K/Pro), MultiCorder ISO recording (4K/Pro), 4–8 vMix Call guests (4K/Pro), 4–8 camera Instant Replay (4K/Pro), 2–4 External/SRT/NDI outputs (4K/Pro), PTZ control (4K/Pro), Data Sources (4K/Pro), and Scripting (4K/Pro).
- **Tier 3 — Hardware/SDK-Dependent Capabilities:** Blackmagic DeckLink / AJA SDI capture & playout with Genlock and RP188 VANC timecode, NewTek NDI 6 runtime, Steinberg ASIO drivers, physical VISCA-over-IP PTZ cameras, MIDI controllers, and Elgato Stream Deck surfaces.
- **Tier 4 — External Protocol / API Capabilities:** SRT Caller/Listener/Rendezvous, RTSP, WebRTC/WHIP, TSL UMD v3.1/v5.0 Tally over UDP, REST/WebSocket remote control, and Singular.live cloud graphics bridges.
- **Tier 5 — Windows-Specific Dependencies Replicated via Native Linux Equivalents:**
  - DirectShow / MediaFoundation cameras → Linux V4L2 (`/dev/video*`) via `v4l2src`
  - DXGI Desktop Duplication → Linux X11 (`ximagesrc`) & Wayland XDG Desktop Portal (`pipewiresrc`)
  - WASAPI / ASIO audio → Linux PipeWire / PulseAudio (`pulsesrc` / `pipewiresrc`) & ALSA (`alsasrc`)
  - DirectShow Virtual Camera DLL → Linux `v4l2loopback` (`/dev/video10`) via `v4l2sink`
  - Direct3D 11 HLSL shaders → Cross-platform Rust CPU/SIMD & GStreamer compositor pipelines
